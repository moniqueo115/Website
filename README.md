# Monique Owens — Property Operations & Portfolio Strategy

Static multi-page website designed to mirror the supplied reference image.

## Files
- `index.html` — home/about page
- `approach.html` — approach page
- `services.html` — services page
- `contact.html` — contact page
- `styles.css` — responsive styling
- `script.js` — mobile navigation, smooth scrolling, contact form behavior
- `assets/hero.jpg` — visual crop from the supplied reference
- `assets/houston.jpg` — Houston skyline crop from the supplied reference

## Put it on GitHub Pages
1. Create a new **public** GitHub repository.
2. Upload all files and the `assets` folder.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save. GitHub will publish the site.

## Contact form
The contact form uses the visitor's email application (`mailto:`), so no server is required. For a hosted form that works without an email client, connect the form to a service such as Formspree or Netlify Forms and replace the JavaScript submit handler.
