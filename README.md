# Monique Owens — Property Operations & Portfolio Strategy

A responsive, multi-page static website designed from the supplied reference.

## Pages

- `index.html` — Home / About
- `approach.html` — Approach
- `services.html` — Services
- `contact.html` — Contact

## Publish with GitHub Pages

1. Create a **public** GitHub repository.
2. Upload **all files and folders in this directory**.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Click **Save**.
7. Wait for GitHub Pages to finish deploying.

Your site will be available at:

`https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/`

## Important

Keep the `assets` folder in the repository. The homepage and CSS use the images in that folder.

The contact form is configured for a static site and opens the visitor's email application. Before launch, replace the email address in `contact.html`, `script.js`, and `index.html` if needed.

## Custom domain

GitHub Pages supports custom domains such as `moniqueowens.co`. Configure the custom domain under **Settings → Pages → Custom domain**, then add the DNS records required by your domain registrar.
